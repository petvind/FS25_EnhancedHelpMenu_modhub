# FS25_EnhancedHelpMenu

Public source + feedback channel for the **FS25_EnhancedHelpMenu** mod published on the Farming Simulator ModHub.

## Get the mod

Install from the [Farming Simulator ModHub](https://www.farming-simulator.com/mods.php) (search the in-game mod browser or the ModHub website for the mod name).

## Report a bug or suggest a feature

Use the **[Issues tab](../../issues/new/choose)** above. Templates are provided so your report includes what's needed (FS25 version, mod version, log snippet, repro steps). Please search existing issues first -- your bug or idea may already be reported.

## Releases

Each ModHub-published version is tagged in this repo (`v1.0.0.0`, `v1.0.1.0`, ...). The contents of the repo at each tag are the exact files inside the ModHub zip for that version.

Active development happens in a private repo that is not exposed here. This repo receives a snapshot of `src\` at each ModHub publish.
